1. **IAM → Roles → Create role.** Trusted entity **AWS service**, use case **EC2**. On permissions, search/select only **AmazonSSMManagedInstanceCore**. Next, role name **MediPulseEc2SSM**, then **Create role**. The Console creates the matching EC2 instance profile automatically. Do not create an IAM user or attach this managed policy to the deployer user instead.
2. **IAM → Policies → Create policy → JSON.** Paste the complete fresh private file `%LOCALAPPDATA%/MediPulse/Private/iam-native-ssm.compact.json`. Next, name **MediPulseNativeSSM**, then create the customer-managed policy. This is a new separate policy; do not replace the working NativePilot JSON or install it inline.
3. **IAM → Users → medipulse-deployer → Permissions → Add permissions → Attach policies directly.** Select **MediPulseNativeSSM**, then **Add permissions**. Keep the old policies attached. Tell the assistant **SSM role and policy ready**.
